# TeamFlow

## Description

TeamFlow is an AI-powered project collaboration platform.

It allows teams to create projects, manage tasks, collaborate with teammates, and use AI to improve productivity.

## Goal

To build a professional full-stack web application using React and Flask as my final-year B.Sc. Computer Science project.
